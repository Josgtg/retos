# Reto: MatchTheRegex

## Descripción

How about trying to match a regular expression.

## Solución

Se nos da la pista de crear un texto que cumpla con una expresión regular, y la obvua pregunta es: ¿Cuál expresión? Por fortuna, esta aparecía en el código fuente de la página y era el siguiente:
```regex
^p.....F!?
```
Teniendo el regex, podemos utilizar la siguiente expresión:
`pxxxxxF!x`
