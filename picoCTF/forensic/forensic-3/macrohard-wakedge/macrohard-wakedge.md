# Reto: MacroHard WeakEdge

## Descripción

I've hidden a flag in this file. Can you find it?

## Solución

Se descomprimía el archivo .ppt, después se buscaba entre los archivos que se generaron. Había un `hidden`, que era un achivo en base64 con las letras separadas por espacios.

`picoCTF{D1d_u_kn0w_ppts_r_z1p5}`
