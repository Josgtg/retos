# Reto: Easy1

## Descripción

The one time pad can be cryptographically secure, but not when you know the key. Can you solve this?
We've given you the encrypted flag, key, and a table to help UFJKXQZQUNB with the key of SOLVECRYPTO. Can you use this table to solve it?.

## Solución

Al ver que nos dieron una llave, debo decir que ignoré el paso de usar la tabla de forma manual y mejor fui a cyberchef, para utilizar el cifrado Vigenère. Para nuestra suerte, el cifrado con la llave dada nos daba lo que faltaba de la flag.
