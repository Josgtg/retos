# Reto: hashcrack

## Descripción

A company stored a secret message on a server which got breached due to the admin using weakly hashed passwords. Can you gain access to the secret stored within the server?

## Solución

Utilicé una herramienta en línea [crackstation](https://crackstation.net/), herramienta que utilizamos en un reto anterior.

Cuando te conectas al servidor que se presenta te muestran ciertos hashes. Ingresé estos hashes en la página y como eran palabras/contraseñas sencillas se podían crackear fácilmente.
