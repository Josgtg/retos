# Reto: substitution0

## Descripción

A message has come in but it seems to be all scrambled. Luckily it seems to have the key at the beginning. Can you crack this substitution cipher?

## Solución

Este reto era muy claro al decirnos que se usaba un algoritmo de sustitución. En este caso, nuestro trabajo se hizo mucho más fácil pues nos incluía una 'llave', que podíamos interpretar como un mapa del abacedario que se usó para encriptar el mensaje.

De nuevo, utilizamos cyberchef, buscamos el algoritmo de sustitución e introducimos la llave.

Este reto fue raro pues el texto como tal nunca me hizo sentido. Sin embargo, el contenido dentro de la llave leía 'substitution...' con números y letras así que sólo copié eso y resultó que estaba bien.

`picoCTF{5UB5717U710N_3V0LU710N_59533A2E}`
