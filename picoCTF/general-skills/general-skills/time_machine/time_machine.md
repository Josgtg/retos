# Reto: Time Machine

## Descripción

What was I last working on? I remember writing a note to help me remember...

## Solución

Este reto era similar a `Commitment Issue`. Nos daban un repositorio, al investigarlo y encontrar un archivo el contenido de este nos invitaba a revisar el historial de commits.

```bash
git log
# commit e65fedb3a72a16c577f4b17023b63997134b307d (HEAD -> master)
# Author: picoCTF <ops@picoctf.com>
# Date:   Tue Mar 12 00:07:29 2024 +0000
#
#     picoCTF{t1m3m@ch1n3_88c35e3b}
```

La flag está ahí nomás...
