# Reto: Rust Fixme 1

## Descripción

Have you heard of Rust? Fix the syntax errors in this Rust file to print the flag!

## Solución

El archivo `main.rs` tenía varios errores simples como un ; faltante, un return mal escrito y un formato incorrecto del `println!`. Una vez arreglados se compila y corre:
`cargo run`.

También era posible usar `cargo check` para que nos dijera los erroes de forma más explícita. El compilador de rust es una joya entonces era fácil de ver los errores.

`picoCTF{4r3_y0u_4_ru$t4c30n_n0w?}`
