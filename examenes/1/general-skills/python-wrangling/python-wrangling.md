# Reto: Python Wrangling

## Descripción

Python scripts are invoked kind of like programs in the Terminal...
Can you run ende.py using password.txt to get flag.txt.en?

## Solución

Este reto básicamente nos intentaba familiarizar con ejecutar scripts de python en consola:
```bash
cat password.txt | python3 ende.py -d flag.txt.en
```
