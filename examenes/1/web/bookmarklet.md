# Reto: Bookmarklet

## Descripción

Why search for the flag when I can make a bookmarklet to print it for me?

## Solución

Al entrar a la página se nos da un snippet de código de javascript. Pegamos este código en la consola del navegador y se nos muestra la flag.

`picoCTF{p@g3_turn3r_6bbf8953}`
